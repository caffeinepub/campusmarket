# CampusMarket Visual Theme

## Design Philosophy

CampusMarket uses a warm, approachable marketplace aesthetic that feels friendly and trustworthy for campus communities. The design avoids generic tech blues and purples in favor of a distinctive coral/amber palette that evokes warmth and human connection.

## Color Palette

### Primary Colors
- **Primary (Coral)**: `oklch(0.65 0.19 25)` - Warm coral for CTAs, active states, and brand elements
- **Primary Foreground**: `oklch(0.99 0.005 40)` - Light text on primary backgrounds

### Secondary Colors
- **Secondary (Peach)**: `oklch(0.95 0.03 45)` - Soft peach for secondary actions and surfaces
- **Secondary Foreground**: `oklch(0.3 0.02 40)` - Dark text on secondary backgrounds

### Neutral Colors
- **Background**: `oklch(0.99 0.005 40)` - Warm off-white
- **Foreground**: `oklch(0.2 0.015 40)` - Dark gray for body text
- **Muted**: `oklch(0.96 0.01 40)` - Light gray for subtle backgrounds
- **Muted Foreground**: `oklch(0.5 0.01 40)` - Medium gray for secondary text

### Semantic Colors
- **Success**: `oklch(0.65 0.15 145)` - Green for success states
- **Warning**: `oklch(0.75 0.15 75)` - Amber for warnings
- **Destructive**: `oklch(0.55 0.22 15)` - Red for destructive actions

### Borders & Inputs
- **Border**: `oklch(0.9 0.01 40)` - Subtle borders
- **Input**: `oklch(0.9 0.01 40)` - Input field borders
- **Ring**: `oklch(0.65 0.19 25)` - Focus ring (matches primary)

## Dark Mode

Dark mode uses brighter, more saturated versions of the primary colors for better contrast:
- **Primary**: `oklch(0.7 0.2 25)` - Brighter coral
- **Background**: `oklch(0.15 0.015 40)` - Dark warm gray
- **Card**: `oklch(0.18 0.015 40)` - Slightly lighter for elevation

## Typography

### Scale
- **H1**: 3xl (mobile) → 4xl (desktop), bold, tight tracking
- **H2**: 2xl (mobile) → 3xl (desktop), semibold, tight tracking
- **H3**: xl (mobile) → 2xl (desktop), semibold, tight tracking
- **Body**: base, normal weight
- **Small**: sm, for metadata and captions
