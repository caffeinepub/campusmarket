# Specification

## Summary
**Goal:** Complete frontend rebuild with sleek, minimalist marketplace UI inspired by modern e-commerce design, plus comprehensive campus marketplace features including verification, multi-photo listings, advanced search, messaging, and seller profiles.

**Planned changes:**
- Redesign entire frontend with clean, minimalist aesthetic featuring elegant typography, generous white space, and cohesive visual identity across mobile and desktop
- Implement campus verification system with .edu email validation and manual campus selection
- Enable multi-photo uploads (up to 5 images) per listing with pricing, sold status, and inventory management
- Build advanced search and filtering with campus-specific categories (textbooks, furniture, electronics, clothing, dorm essentials, course materials, move-out sales)
- Create comprehensive user profile pages with seller ratings, listing history, verification badges, and campus affiliation
- Implement buyer-seller messaging system with typing indicators, read receipts, and quick offer buttons
- Add price suggestion feature based on item condition and comparable listings
- Implement urgent sale tags for end-of-semester listings with search prioritization
- Add campus meetup location suggestions for safe transaction coordination
- Implement saved searches with notifications for matching new listings
- Redesign home page with personalized recommendations, quick actions, recently viewed items, and trending section
- Redesign listing detail pages with large image carousels, clear product info, seller preview, and integrated safety tips
- Redesign search results with grid-based cards, elegant filtering UI, and category chips
- Create cohesive design system with warm neutral color palette (avoiding blue/purple), elegant typography, consistent spacing, and smooth micro-interactions

**User-visible outcome:** Users experience a beautiful, premium campus marketplace with sleek mobile and desktop interfaces, can verify their campus affiliation, create rich multi-photo listings, use advanced category-specific search and filters, message sellers seamlessly, view detailed seller profiles with ratings, save searches for notifications, mark urgent sales, get pricing suggestions, and discover safe campus meetup locations—all with a polished, minimalist design aesthetic.
