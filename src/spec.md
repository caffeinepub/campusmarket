# Specification

## Summary
**Goal:** Add analytics dashboard, theme toggle, advanced sorting, featured listings, review system, favoriting, comparison tool, and recently viewed tracker.

**Planned changes:**
- Create analytics dashboard page at /insights with sales trends, view counts, engagement metrics charts, time range selector (7/30/90 days), and CSV export
- Implement dark/light theme toggle with persistence across all pages
- Add advanced sorting options: relevance, price (ascending/descending), newest, popularity, condition quality, distance from user
- Create featured/spotlight sections on home page and search results with distinct visual styling
- Build review and rating system allowing buyers to rate sellers, display seller reputation scores on listings and profiles
- Add favoriting functionality with heart icon and optimistic UI updates, create saved page for favorited listings
- Implement comparison tool allowing users to select and compare up to 3 listings side-by-side
- Create recently viewed tracker displaying last 10 viewed items on home page strip and dedicated page

**User-visible outcome:** Users can analyze their listing performance through an interactive dashboard with downloadable reports, switch between light and dark themes, sort listings by multiple criteria including distance and popularity, discover featured listings, read and write seller reviews with reputation scores, save favorite listings, compare up to 3 listings side-by-side, and quickly access recently viewed items.
